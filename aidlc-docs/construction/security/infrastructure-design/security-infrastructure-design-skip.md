# Infrastructure Design — U-06 `security` — SKIP 提案

**作成日**: 2026-07-17
**ステージ**: CONSTRUCTION - Infrastructure Design（ユニット 6 / 8、CONDITIONAL）
**判定**: **SKIP を提案**（検証のうえ、U-06 固有のインフラ設計対象がないことを確認）

---

## 1. 本 skip 提案は「確認したうえで」の判定である

U-02〜U-05 の skip と異なり、**U-06 には固有のインフラ要件が存在しうる**——監査ログの**追記専用ストレージ**（SECURITY-14, MU-04, US-04）である。これはアプリケーションの外側（OS・ファイルシステム・cron）に属する統制であり、「U-06 だから skip」と機械的に判断すべきではない。

そこで `construction/shared-infrastructure.md` を**実際に確認した**。結論として、**U-01 の Infrastructure Design スロットで既に完全に確定済み**である。

---

## 2. 監査ログのインフラは U-01 で確定済み（実確認）

`shared-infrastructure.md` セクション 3.3 および 7 に、以下がすべて規定されている。

| 項目 | 規定内容 | 出典 |
|------|---------|------|
| 配置 | **暗号化ボリューム上の `audit/` ディレクトリ** | 3.2, 3.3 |
| 属性 | **`chattr +a`（追記専用）** | 3.3 |
| ファイルシステム | **ext4 または XFS**（`chattr +a` 対応が必須）| 3.3 |
| 許可される操作 | **ファイル末尾への追記のみ可能** | 3.3 |
| ローテーション | **特権 cron が日次で実行**（`chattr -a` → `mv` → `chattr +a` → 新 `current.jsonl` 作成 → 90 日超を削除）| 3.3 |
| 保持期間 | **90 日以上**（SECURITY-14）| 3.3, 6 |
| **最小権限の分離** | **アプリアカウント**: `current.jsonl` への**追記のみ**。`audit/` への書き込み権限なし、**`chattr` 実行不可**。**cron アカウント**: `audit/` の全操作と `chattr`。ただし**業務 DB への権限なし** | 3.3, 7 |
| PII | 監査ログは**個人情報を含まない**（職員 ID のみ）と明記 | 3.1 |

**`shared-infrastructure.md` は監査ログの所有ユニットを U-06 と明記している**（セクション 3.1 の表）。すなわち、U-01 の時点で「U-06 が使うインフラ」として設計済みであり、**U-06 側に残された設計判断はない**。

**SECURITY-14 の「アプリケーションのロールが自身のログを削除する権限を持たない」は、この権限分離で満たされている**（U01-H16 discharged）。

## 4. `argon2-cffi` はインフラ設計対象ではない

`argon2-cffi` は**アプリケーション依存**（NFR Requirements で確定・固定）であり、インフラサービス（別プロセス・別ホスト・ミドルウェア）ではない。Code Generation で固定・pip-audit/SBOM を行う（U06-H9）。

---

## 5. 運用への申し送り（U-06 のインフラ前提）

U-06 のコードが正しく動作するために、**運用が以下を満たす必要がある**（U-01 で規定済み、U06-H6 として再掲）:

1. `audit/current.jsonl` に **`chattr +a` が付与されている**こと
2. ファイルシステムが **ext4 / XFS** であること
3. **アプリアカウントが `chattr` を実行できない**こと（実行できてしまうと MU-04 の対策が無効化される）
4. **特権 cron のローテーション**が設定されていること（未設定だとファイルが無限に成長する）

これらは Build and Test / Operations で確認する。

---

## 6. 結論

**Infrastructure Design を SKIP することを提案する。**

- 7 カテゴリすべてが確定済み（U-01）または N/A
- **唯一の実質的な論点だった監査ログの追記専用ストレージは、U-01 で完全に規定済みであることを実確認した**（推測ではない）
- U-06 は新しいインフラサービスを追加しない。セッションは注入されるポート、`argon2-cffi` はアプリ依存
- ブロッキング所見なし

skip 承認後、U-06 の **Code Generation** に進む。
