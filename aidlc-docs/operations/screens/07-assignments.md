# 画面別説明書 — 割当結果画面

**要件**: US-21（一覧表示）/ US-22（手動修正）／関連: US-23（ピン留め再最適化）
**利用者**: P-01（割当担当者）
**左ナビ**: 「割当結果」
**前提**: イベントが選択され、最適化が完了していること

---

## 画面の構成

### (1) 割当一覧（表）

| 列 | 意味 |
|----|------|
| 職員ID | 割り当てられた職員 |
| 施設ID | 割当先の施設 |
| 確定 | 手動で確定（ピン留め）された割当は「確定」と表示 |

- 割当が 0 件のときは「割当がありません」と表示されます（先に最適化を実行してください）。

### (2) 手動修正フォーム

| 項目 | 種類 | 必須 | 説明 |
|------|------|------|------|
| 職員ID | 入力欄 | ○ | 変更対象の職員 |
| 施設ID | 入力欄 | ○ | 変更先の施設 |
| 割当を変更 | ボタン | — | 指定の職員を指定の施設へ変更 |

---

## 操作手順（手動修正）

1. 一覧で現在の割当を確認します。
2. 手動修正フォームに **職員ID** と **施設ID** を入力します。
3. **[割当を変更]** を押します。
4. 制約に反しなければ、一覧が更新されます。
5. 制約に反する場合は、**どの制約に反したか**が一覧表示され、変更は反映されません（元の割当は保持されます）。

---

## 手動修正の安全装置（重要）

あなたが割当を変更すると、システムが自動で制約を検査します。反する変更は受け付けられず、違反した制約が表示されます。

| 制約 | 例の表示 | 意味 |
|------|---------|------|
| C1 | 「[C1] 施設F1の必要人数を超えています (施設: F1)」 | 施設の必要人数を超過 |
| C2 | 重複 | 同一職員を複数施設に割当 |
| C3 | 資格要件 | 資格要件（責任者は管理職 等）を満たさない |
| C4 | 従事可否 | 従事不可の職員を割当 |
| C5 | 部署上限 | 1 部署からの割当上限を超過 |

> 制約の判定はシステム（最適化エンジン）が一元的に行います。無理な割当を誤って確定する心配はありません。

---

## エラーと対処

| 状況 | 表示 | 対処 |
|------|------|------|
| イベント未選択 | 「先にイベントを選択してください」 | イベント画面へ |
| 割当が 0 件 | 「割当がありません」 | 最適化を実行 |
| 制約違反 | 制約IDと詳細の一覧 | 表示に従い別の職員／施設に変更 |
| 必須項目が空 | 「職員IDを選択してください」等 | 入力する |

## 本 PoC の制約

- **割当結果の CSV エクスポート（US-25）は未提供**です（申し送り）。
- **ピン留めによる部分再最適化（US-23）**は、最適化画面の**増分（INCREMENTAL）モード**で前回割当を踏まえた再計算として実現します。個別のピン留め UI は将来提供予定です。
- 割当ごとの移動時間・費用の数値表示（移動負担の可視化）は、応答項目の拡張後に提供予定です（当面は最適化画面の目的関数値・最適性ギャップを参照）。
