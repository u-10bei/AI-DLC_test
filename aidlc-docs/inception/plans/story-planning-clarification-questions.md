# 曖昧さ 1: 制約のソフト化（Q7 = C の詳細化）

Q7 で **C（特定の制約をソフト制約に降格させて再計算できる）** を選択されました。しかし、**どの制約を降格できるのか**、および**降格時のペナルティをどう定めるのか**が未確定です。

要件で定義されているハード制約は以下の 5 件です（FR-04.3）。

| ID | 制約 | 降格した場合に起こること |
|----|------|------------------------|
| C1 | 定員充足（各施設に必要人数を割り当てる） | 施設が定員割れのまま運用される |
| C2 | 一意割当（1 職員は高々 1 施設） | 1 人の職員が同時刻に複数の施設へ割り当てられる（物理的に不可能） |
| C3 | 職種・資格・役職（責任者は管理職に限る等） | 資格を持たない職員が責任者として配置される |
| C4 | 従事可否（休暇・育児介護・健康配慮） | 休暇中・健康上の配慮が必要な職員が派遣される |
| C5 | 部署継続性（同一部署からの同時割当上限） | 特定部署の通常業務が停止する |

**C2 は物理法則に反するため降格不可能です。** それ以外については、業務判断が必要です。
