# 矛盾: 比較の方法論（CQ4）と提供可能なデータ（CQ5）

**CQ4 = A** では「過去のイベント条件（**施設一覧、必要人数、当時の職員名簿と従事可否**）をシステムに投入し、同一条件で最適化を実行する」を選択されました。

**CQ5 = A, B** では、提供可能なデータを以下に限定されました。

- A) イベント情報（イベント名、実施日）

提供されないのは以下です。

つまり、CQ4 が要求する「必要人数」「当時の職員名簿と従事可否」が、CQ5 では提供されません。文字どおりには CQ4=A を実行できません。

## ただし、B から導出することで解決できます

実績データ（B: 職員 ID → 施設 ID の対応）から、以下を導出できます。

| 必要な情報 | 導出方法 | 正確性 |
|-----------|---------|--------|
| 各施設の必要人数 | 実績でその施設に割り当てられていた**職員数を数える** | 定義により正確 |
| 従事可能な職員の集合 | 実績に**登場する職員の集合**そのもの。実際に従事した以上、当時従事可能だったことは自明 | 定義により正確 |
| 職員の居住小学校区 | 現在の職員マスタの値を使用（当時の値は取得不可） | **近似**（下記参照） |
| 職種・資格・役職、所属部署 | 現在の職員マスタの値を使用 | **近似** |

この導出により、比較は「**同一の職員集合・同一の施設・同一の施設別必要人数に対し、割当ルールだけを変えた再最適化**」となります。因果関係は明確で、削減効果は割当ルールの差のみに帰属します。

**近似に伴う限界**: 居住小学校区・所属部署は「現在の値」を使うため、算出される移動時間・費用の**絶対値**は当時の実際の値と一致しません。ただし、ベースラインと最適化結果の**両方**が同じ現在の値で評価されるため、**両者の差（削減効果）は妥当**です。この限界は要件の前提条件として記録します。

## Clarification Question 2
