## 2. 該当する NFR

### NFR-U05-P01: 比較の実行方式（性能, Q3=A）

**要件**: 比較レポートの生成が API をブロックしない。

**達成手段**: 比較は U-04 の求解 1 回（最大 300 秒）+ O(割当数) の集計。**U-01 のジョブワーカープロセス**で実行（U-07 が配線）。U-05 固有の性能目標は設けず、U-04 の NFR-P02 に従う。

---

### NFR-U05-R01: fail closed の比較（信頼性, SECURITY-15）

**要件**: 再現問題が実行不可能でも、レポートを捏造しない。

**達成手段**: BR-CMP09。U-04 の `InfeasibilityDiagnosis`（原因 + 施設/制約 ID）をそのまま提示する。

---

### NFR-U05-R02: 再現性（信頼性, Q4=A）

**要件**: 同一入力で再現可能な比較。

**達成手段**: 最適化部分は U-04 の再現性（シード・ワーカー数固定）に従う。集計は決定的。保証範囲も U-04 準拠（タイムアウト時の最良解は保証外）。

---

### NFR-U05-M01: 依存の追加なし・ユニット境界（保守性, Q1/Q2）

**要件**: 新規プロダクション依存を増やさず、ユニット境界を保つ。

**達成手段**: **プロダクション依存ゼロ**。U-02/U-03/U-04 を組み合わせる。リンタ契約で `distance_cost`（U-02）を許可リストに追加（U05-H1）、上位ユニットと `pydantic`/`fastapi` を禁止。

---

### NFR-U05-S01: 個人情報の非露出（セキュリティ, SECURITY-03）

**要件**: 比較レポート・CSV に個人情報を含めない。

**達成手段**: Functional Design で対応済み（BR-CMP11）。集計指標 + 職員 ID・施設 ID のみ。
