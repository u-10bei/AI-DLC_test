# デプロイアーキテクチャ — U-01 `shared-kernel`

**作成日**: 2026-07-09
**ステージ**: CONSTRUCTION - Infrastructure Design（ユニット 1 / 8）

---

## 1. 結論

**U-01 `shared-kernel` は独立してデプロイされない。**

本システムはモノリス（Units Generation Q1=A）である。U-01 は、バックエンドプロセスに**インポートされるモジュール**として存在する。独自のデプロイ成果物、独自のプロセス、独自のエンドポイントを持たない。

---

## 2. モノリス内での位置づけ

```text
  +-------------------------------------------------------------------+
  |  PoC Server (internet-side)                                       |
  |                                                                   |
  |  +-------------------------------------------------------------+  |
  |  |  API Process  (uvicorn + FastAPI)                           |  |
  |  |                                                             |  |
  |  |    src/api-orchestration/   U-07                            |  |
  |  |    src/security/            U-06                            |  |
  |  |    src/comparison-report/   U-05                            |  |
  |  |    src/optimization-engine/ U-04                            |  |
  |  |    src/data-management/     U-03                            |  |
  |  |    src/distance-cost/       U-02                            |  |
  |  |    src/shared-kernel/       U-01  <-- 本ユニット            |  |
  |  |                                                             |  |
  |  +-------------------------------------------------------------+  |
  |                                                                   |
  |  +-------------------------------------------------------------+  |
  |  |  Job Worker Process                                         |  |
  |  |                                                             |  |
  |  |    src/optimization-engine/ U-04                            |  |
  |  |    src/distance-cost/       U-02                            |  |
  |  |    src/data-management/     U-03                            |  |
  |  |    src/shared-kernel/       U-01  <-- 本ユニット            |  |
  |  |                                                             |  |
  |  +-------------------------------------------------------------+  |
  |                                                                   |
  |  +-------------------------------------------------------------+  |
  |  |  Frontend  (U-08)                                           |  |
  |  |    REST/JSON over HTTP でのみバックエンドと通信する          |  |
  |  +-------------------------------------------------------------+  |
  |                                                                   |
  +-------------------------------------------------------------------+
```

**U-01 は 2 つのプロセス（API プロセスとジョブワーカープロセス）の双方にロードされる。** どちらもドメイン型を必要とするためである。

**U-08 frontend は U-01 を含まない。** NFR-M05 により、フロントエンドはバックエンドのいかなるモジュールも import しない。リンタ規則 R-1 がこれを機械的に強制する。

---

## 3. デプロイ成果物

| 項目 | U-01 の状態 |
|------|-----------|
| 独立したデプロイ成果物 | **持たない** |
| 独立したプロセス | **持たない** |
| 独立したコンテナイメージ | **持たない** |
| 公開するエンドポイント | **持たない** |
| 環境変数・設定ファイル | **持たない**（設定は `P-06 ConfigPort` 経由。U-07 が所有） |
| ヘルスチェック | **持たない** |
| 外部への通信 | **一切行わない** |

**U-01 は `src/shared-kernel/` ディレクトリに配置される Python モジュール群である。** バックエンドのデプロイ成果物に含まれてデプロイされる。

---

## 4. 起動時の挙動

U-01 は**起動時の初期化処理を持たない**。

| 一般的なモジュールが行うこと | U-01 |
|------------------------|------|
| DB 接続プールの初期化 | **行わない** |
| 設定ファイルの読み込み | **行わない** |
| ログハンドラの登録 | **行わない** |
| 外部サービスへのヘルスチェック | **行わない** |
| バックグラウンドタスクの起動 | **行わない** |

インポートされた時点で、型定義・例外クラス・列挙値の変換表が利用可能になる。それだけである。

**この性質により、U-01 は起動順序の制約を持たない。** どのユニットよりも先に、副作用なくインポートできる。

---

## 5. 依存関係（デプロイ時）

| 依存 | 内容 |
|------|------|
| **プロダクションコード** | **Python 標準ライブラリのみ**（`dataclasses`, `enum`, `typing`, `datetime`, `math`） |
| **テストコード** | `hypothesis`, `pytest` |

**サードパーティのランタイム依存を持たない。** これは意図した設計である（`nfr-design/nfr-design-patterns.md` パターン 1: Pydantic を U-07 の API 境界に閉じ込めた）。

**SECURITY-10 への含意**: U-01 はプロダクションの依存グラフに新たなパッケージを追加しない。脆弱性スキャン（`pip-audit`）の対象となる依存が、U-01 に起因して増えることはない。

---

## 6. 実運用移行時の影響

Units Generation Q9=B により、実運用のデプロイ構成は PoC のユニット境界とは無関係に再構成する。

| 移行項目 | U-01 への影響 |
|---------|-------------|
| バックエンドを庁内オンプレミスへ分離 | **なし**。U-01 はバックエンドプロセスとともに移動する |
| SQLite → PostgreSQL | **なし**。U-01 は永続化を知らない |
| 職員本人による従事可否申告（A-08） | **なし**。`AvailabilityDeclaration` の型は既に `(職員, イベント)` の組を表現している |
| 全職員分のアカウント管理 | **なし**。U-06 の責務 |

**U-01 は、実運用移行によって変更されない唯一のユニットである。**

これは偶然ではない。U-01 が標準ライブラリのみに依存し、インフラを一切持たないことの帰結である。
