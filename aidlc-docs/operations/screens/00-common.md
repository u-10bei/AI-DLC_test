# 画面別説明書 — 共通（画面枠・ナビ・エラー）

**対象**: 全画面共通の枠組み。個別画面は各ファイルを参照。
**注**: 本書は**実装済み UI に忠実**な操作手順（項目・ボタン・メッセージ単位）です。要件との対応・責務の流れは `operations/manual-P-01-coordinator.md` 等のペルソナ別説明書を参照してください。

---

## 1. 画面全体の構成（ログイン後）

```
┌─────────────────────────────────────────────┐
│ ヘッダー: システム名 │ ログイン中ユーザー名 │ [ログアウト] │
├───────────┬─────────────────────────────────┤
│ 左ナビ    │                                 │
│ ・イベント │        現在の画面（メイン領域）   │
│ ・マスタ  │                                 │
│ ・申告取込 │                                 │
│ ・充足状況 │                                 │
│ ・最適化  │                                 │
│ ・割当結果 │                                 │
└───────────┴─────────────────────────────────┘
```

- **ヘッダー右**: 現在ログイン中のユーザーID と **[ログアウト]** ボタン。
- **左ナビ**: 6 つの画面へ移動できます。現在の画面は下線・太字で示されます。
- ログインしていない状態では、ログイン画面のみが表示されます。

---

## 2. 画面をまたぐ「選択中のイベント」

- 申告取込・充足状況・最適化・割当結果の各画面は、**選択中のイベント**を対象に動作します。
- 選択中イベントは、**イベント画面でイベントを作成すると自動的に設定**されます。
- イベントが未選択のまま上記画面を開くと、「先にイベントを作成・選択してください」と表示されます。→ 先にイベント画面へ。

---

## 3. 共通の操作フィードバック

| 表示 | 意味 | 対応 |
|------|------|------|
| 「読み込み中…」 | データ取得中 | 待つ |
| （データなしの案内） | 対象データが 0 件 | 前段の取込・作成を確認 |
| 赤字のメッセージ（role=alert） | 入力エラー／サーバーからのエラー | 内容に従い修正 |
| [再試行] ボタン | 取得に失敗 | 押して再取得 |

---

## 4. 共通のエラーと対処

| 症状 | 原因 | 対処 |
|------|------|------|
| 突然ログイン画面に戻る | セッション切れ（自動失効） | 再ログイン |
| 「この操作は許可されていません」 | 権限不足（認可） | 管理者に確認 |
| 画面が全く開けない（庁外） | 送信元 IP 制限 | 庁内ネットワークから接続 |
| 「エラーが発生しました」（画面全体） | 表示中の想定外エラー | ページ再読み込み |

- エラーメッセージには内部情報（技術的な詳細）は含まれません。表示された文言に従って操作してください。

---

## 5. 入力の基本ルール

- **必須項目**が空の場合、送信は行われず、項目ごとに赤字で不足が示されます（サーバーに送る前にその場で気づけます）。
- サーバー側でも検証が行われ、形式不正（例: 日付でない）や規則違反は**サーバーのメッセージがそのまま表示**されます。
- CSV 取り込みでエラーがある場合、**行番号付き**で理由が一覧表示されます（個人情報は表示されません）。
